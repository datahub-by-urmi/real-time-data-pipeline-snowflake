# Python Customer Data Generator

This folder contains my Python Jupyter notebook used to generate fictional customer data for the Snowflake data pipeline project.

I used the Faker library to generate 10,000 customer records and saved them as CSV files.

These CSV files are picked up by Apache NiFi and uploaded to Amazon S3 for further processing in Snowflake.

**Tools:** Python, Faker, JupyterLab, CSV
